# 持ち時間（60秒＋1ターン15秒の秒読み方式）

## 動機

対局の持ち時間ルールとして、将棋の秒読みに準じた「持ち時間60秒＋1ターン15秒」の方式を導入したい。すなわち、15秒を切ったら即座に強制ランダム行動となる従来の仕組みではなく、15秒を超えた分だけ持ち時間60秒が実時間で減っていく仕組みにする。

従来（`docs/2026-08-14-card-system-phase-b.md` 3.7/3.8）は、カードフェーズ・指し手フェーズそれぞれに15秒のハードな締切があり、超過すると即座に `AShogiPlayerController::ForceRandomCardOrPass`（カード） / `AShogiBoardManager::PickRandomLegalAction`（指し手）による強制ランダム行動が発生していた。

## 仕様

- カードフェーズ・指し手フェーズは、これまで通りそれぞれ独立して15秒の無料猶予（フリー期間）を持つ。
- フリー期間を超えても即座に強制行動は発生しない。代わりに、その側の持ち時間（初期値60秒、対局を通して両側とも保持）から超過分がリアルタイムで減っていく。
- フリー期間内に行動（カードのプレイ/パス、指し手/駒打ち）を終えた場合は、持ち時間は減らない。
- 持ち時間が0になった時点で、その側の**時間切れ負け**としてゲームを終了する（既存の `bGameOver`/`Winner` 仕組みを流用）。
- 持ち時間は対局を通して減る一方で、途中で回復・加算はされない（Fischer方式の時間加算ではない）。
- 画面上の残り時間カウントダウン表示（`AShogiGameState::CurrentPhaseTimerEndTime` を参照する既存UI）は、フリー期間中は15秒のカウントダウンを、持ち時間消費中は持ち時間の残量カウントダウンをそのまま表示する（表示の仕組み自体は変更していない）。

## 設計

### 永続的な持ち時間の保持

`AShogiGameState`（`Source/Shogi/Gameplay/ShogiGameState.h/.cpp`）に、各側の持ち時間を保持するレプリケート済みフィールドを追加した。

- `float TimeBankSeconds_Sente = 60.f;` / `float TimeBankSeconds_Gote = 60.f;`
- `float GetTimeBankSeconds(EPlayerSide Side) const;`（UI・内部ロジック共通の参照用ゲッター）

### フリー期間→持ち時間消費への遷移

`AShogiBoardManager`（`Source/Shogi/Gameplay/ShogiBoardManager.h/.cpp`）に以下を追加し、既存の `CardPhaseTimerHandle`/`MovePhaseTimerHandle`（15秒固定値 `CardPhaseTimeoutSeconds`/`MovePhaseTimeoutSeconds` は「フリー期間の長さ」として意味を変えつつそのまま流用）を段階的に使い回す形にした。

- `HandleCardPhaseFreePeriodExpired()` / `HandleMovePhaseFreePeriodExpired()`: 旧 `HandleCardPhaseTimeout`/`HandleMovePhaseTimeout` を置き換え。フリー期間15秒が切れた時点で発火し、即座に強制行動はせず `BeginBankDepletion()` を呼ぶ。
- `BeginBankDepletion(FTimerHandle& PhaseTimerHandle)`: 現在の手番側の残り持ち時間を取得し、`BankDepletionStartTime`（`GetServerWorldTimeSeconds()`）を記録。持ち時間がまだ残っていれば、その残量分だけ `PhaseTimerHandle` を `HandleTimeUp` 宛に再セットし、`SetPhaseTimerEndTime()` でUIのカウントダウン表示先を持ち時間の残量に切り替える。残り時間が既に0なら即座に `HandleTimeUp()`。
- `EndBankDepletion(EPlayerSide Side)`: フェーズが正常に解決した（カードを出した/パスした、指し手/駒打ちが成立した）タイミングで呼ぶ。`BankDepletionStartTime` が設定されていれば、経過時間を該当側の `TimeBankSeconds_*` から差し引き、`BankDepletionStartTime` を -1 に戻す。フリー期間内に解決していた場合（`BankDepletionStartTime < 0`）は何もしない。
  - 呼び出し箇所: `OnCardPhaseResolved`（カードフェーズ解決時）、`ApplyMove`・`ApplyDrop`（指し手/駒打ちが成立し `UpdateStandLayout()` を呼んだ直後、`AdvanceTurn()` の前）。不正なリクエストで早期 `return` する経路では呼ばない（＝実際に行動が成立した場合のみ持ち時間を確定させる）。
- `HandleTimeUp()`: 持ち時間消費中にタイマーが満了した場合に発火。該当側の持ち時間を0にし、`bGameOver=true`・`Winner`を相手側に設定して `OnRep_GameOver()` をブロードキャスト、両フェーズタイマーをクリアする。

### 強制ランダム行動の廃止

フリー期間超過時に即座に強制行動を起こす仕組みは、上記の持ち時間消費に置き換わったため撤廃した。

- `AShogiPlayerController::ForceRandomCardOrPass()`（宣言・実装とも）を削除。呼び出し元は `HandleCardPhaseFreePeriodExpired` のみだったが、そこでは呼ばなくなったため完全に不要になった。
- `AShogiBoardManager::PickRandomLegalAction` は指し手フェーズの強制行動には使われなくなったが、`AShogiSinglePlayerVsAIGameMode::MakeAIMove`（CPU対戦相手の着手選択）で引き続き使用されているため関数自体は維持した。

### 挙動の変化に関する補足

持ち時間が尽きるまでは行動を待ち続けられる（フリー期間超過時に自動で何かが起こることはない）。AI側（コントローラが存在しない側）は従来通りこの仕組みの対象外で、`StartCardPhaseForCurrentTurn` はコントローラがいない側にはそもそもタイマーを起動しない。
