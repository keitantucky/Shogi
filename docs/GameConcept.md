# 将棋×カード カオスバカ対戦ゲーム（仮）企画概要資料

## 1. コンセプト＆ターゲット

### コンセプト

伝統的な「将棋」の厳密なロジックに「ぶっ壊れ効果のカード」を掛け合わせた、ハチャメチャ展開と爆笑を生むマルチ対戦バカゲー。

### ターゲット

ボイスチャットでワイワイ盛り上がりたいフレンド層・配信者。

### ゲームデザイン方針

- シリアスな心理戦やミリ単位のバランス調整は不要。「大技の応酬」と「ランダムで発生するイベント」「予測不能の試合展開」を楽しむ。
- 長考を防ぎ、テンポ感を最優先（1試合10分弱でサクッと遊べるスケール）。

## 2. 基本ルール＆システム

### ① 将棋×カードの基本構造

- **盤面・駒**: 9×9の将棋盤、および通常の将棋の駒配置。
- **山札＆手札**:
  - 山札: 30枚（お互いに山札を持つが中身は同じ）。
  - 手札: 最大3枚（毎ターン開始時に1枚ドロー）。
- **カード使用**: 自分のターン開始時、手札から1枚だけ使用可能（コストなし）。
- **プレイ順序の固定**: 「カード使用」➔「駒の移動」の順番で固定。

### ② 駒の持ち帰り（取った駒）

- 相手から取った駒は自分の持ち駒として再利用可能。
- カードで強化されたステータスもそのまま引き継がれる（ハイパー化した駒を奪うリターンが大きい反面、奪われた際のリスクも跳ね返る）。

## 3. カード効果一覧（将棋ゲームプロトタイプカード効果10選）

### カード分類

- **永続**: 文字通り効果が永続する。例えばカードによりステータスを強化し、その駒が取られた場合、相手はステータスが強化されたままの駒を使用することができる。
- **即時**: その場で効果が発動する。その後は永続に同じ。
- **時限**: ターン数制限や数ターン後に効果が発動する。数ターン後に効果が発動する場合、該当ターン開始時に効果が発動する。

## 4. テンポ維持＆飽きさせない仕組み

### ① テンポ爆速化（15秒タイマー）

- 1ターン制限時間は15秒。
- **時間切れペナルティ**: 手札からランダムで1枚のカードが強制発動（事故発生率アップ）。

### ② 勝利条件の拡張

- 通常の「王手・玉将奪取」に加え、「相手陣地の一番奥に自分の王が到達（トライ）」でも勝利可能。

## 5. ゲームフロー

```
[ 1. 対局準備（Setup） ]
  ├─ 81マスの盤面＆初期駒配置を動的生成
  ├─ 山札（30枚）をシャッフル／各プレイヤーに初期手札（3枚）を配布
  └─ 先攻・後攻の決定

[ 2. 特殊ルールルーレット（Rule Event） ]
  └─ 試合ごとの「ランダムルール」をルーレットで1つ決定・適用
      (例:「本日の将棋：歩が全員『銀』の動き」「10ターン後に盤面が90度回転」など)

[ 3. ターンサイクル（Loop） ※制限時間15秒（カード選択or未使用選択後にカウント開始） ]
  ├─ ドローフェーズ  : 共通山札からカードを1枚引く（手札上限3枚）
  ├─ カードフェーズ  : 手札から1枚選択して発動（任意 / 時間切れで強制ランダム発動）
  └─ 将棋フェーズ    : 盤上の駒を1つ移動（または持ち駒を打つ）

[ 4. 終了判定 / 状態更新 ]
  ├─ 勝敗判定（王の撃破、または王の敵陣トライ達成か？）
  └─ 相手のターンへ移行
```
